features:
  - title: Detects the track
    body: A content script reads the song from the YouTube page as soon as you open the extension.
  - title: Finds the lyrics
    body: No single lyrics source covers everything, so Nuqta searches and reads candidate pages to build a clean line list.
  - title: Explains, not just translates
    body: 'Each line gets a translation and a note on what it is doing: the image it uses, the reference it assumes you know.'
  - title: Aligned columns
    body: Original, translation and meaning line up, so your eye can move between them while the song plays.

build:
  - title: Detect
    body: A content script on YouTube reads the track from the page and passes it to the service worker.
  - title: Find lyrics
    body: A FastAPI backend searches through DuckDuckGo and scrapes candidate pages with httpx and BeautifulSoup, since no single lyrics source covers everything.
  - title: Interpret
    body: Mistral 7B through Ollama translates and explains line by line, locally, so there is no per-song API bill.
  - title: Present
    body: The popup renders original, translation and meaning as aligned columns so your eye can move between them while the song plays.
stack: [Manifest V3, FastAPI, Ollama, Mistral 7B, BeautifulSoup]

Lyrics on the open web are messy: ads in the middle of verses, repeated choruses, transliterations mixed with scripts. Getting a clean line list out of arbitrary HTML took more iteration than the model prompting did.

Keeping the model aligned line for line was the other half. If it merges or drops a line, the three columns stop matching, so the response format has to be constrained rather than free prose.
